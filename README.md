# Bestiary

Переносимая фототека для Windows x64. Альбомы берутся из папок внутри `Photos`. Подпапки `Photos/Dere` отображаются отдельными альбомами.

- В режиме «Только фото» кадры отображаются целиком и без подписей. Прокрутка непрерывная, размер меняется ползунком. Можно включить один столбец или вернуть карточки с подписями.
- Нажми на изображение, чтобы открыть его на весь экран. Стрелки и нижняя лента листают кадры, колесо масштабирует, мышь перемещает увеличенный кадр. `F` добавляет в избранное, пробел включает слайд-шоу или управляет видео, `Tab` скрывает панели, `Esc` закрывает просмотр.
- Меню изображения меняет обложку, добавляет его в серию и позволяет скрыть превью. Выбери несколько кадров через Ctrl+клик для назначения серии или альбома. Два кадра можно сравнить рядом с общим масштабом.
- Щёлкни правой кнопкой по кадру, чтобы скопировать исходный файл для вставки в Проводнике, скопировать изображение в буфер или переместить файл из фототеки Bestiary в корзину Windows.
- Кнопка «Импорт» копирует изображения и видео из выбранной папки в `Photos/Imports` и открывает «Входящие». Назначение альбома меняет запись в каталоге. Последнее назначение можно отменить из «Входящих». Совпадения проверяются по SHA‑256.
- Для переноса закрой программу и скопируй всю папку с `Bestiary.exe`, `Photos` и `Data`. Каталог `Data/catalog.json` хранит относительные пути, избранное, обложки и серии. `Data/Thumbnails` можно восстановить из оригиналов.

В просмотре доступны PNG, JPEG, WebP, BMP, TIFF, анимированный GIF и MP4 с кодеками, установленными в Windows.

## Сборка

Требуется .NET 10 SDK. Готовая сборка запускается без отдельно установленного .NET.

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```

Необязательная иллюстрация главной страницы читается из `Data/Citadel.png`. Репозиторий содержит код, локальные изображения в него не входят.
